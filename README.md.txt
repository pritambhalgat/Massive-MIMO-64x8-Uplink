# 64×8 Massive MIMO Uplink Simulation

This project implements a Massive MIMO uplink simulator with:

- 64 BS antennas
- 8 users
- Rayleigh fading channels
- Imperfect CSI
- MRC detection
- ZF detection
- MMSE detection

## Performance Metrics

- BER
- Spectral Efficiency
- Energy Efficiency

## Tools

- Python
- NumPy
- Matplotlib
- Jupyter Notebook
